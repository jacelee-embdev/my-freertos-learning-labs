# STM32F103C8T6 密码门禁系统（原版）

## 项目简介

本综合实验实现带非易失存储的矩阵键盘密码门禁。系统启动时从 W25Q128 读取密码；未设置时进入首次设密流程，否则显示密码输入界面。数字键用于输入，`#` 用于确认，`*` 进入修改密码流程。密码正确时短鸣并打开继电器门锁，3 秒软件定时器到期后自动落锁；连续三次输入错误会触发长鸣报警。OLED 显示、蜂鸣器和门锁分别由独立任务处理。

## 主要功能

- 在 W25Q128 中保存和读取最多 10 字节密码。
- 通过多个消息队列分发键盘、显示、蜂鸣器和门锁命令。
- 使用事件组记录正确、错误和多次失败报警事件。
- 使用互斥量保护 SPI Flash 访问。

## 硬件连接

4×4 键盘使用 PB0–PB2、PB10 和 PB11–PB14；OLED 的 SCL/SDA 接 PB8/PB9；蜂鸣器接 PB5，门锁继电器接 PB6。W25Q128 的 CS/SCK/MISO/MOSI 接 PA4–PA7。

## 使用方法

打开 `Projects/MDK-ARM/STM32F103.uvprojx`，编译下载。首次启动输入新密码并按 `#` 保存；正常模式输入密码后按 `#` 验证，按 `*` 可先验证旧密码再设置新密码。

## 主要文件

- `Drivers/BSP/app_sys_orchestrator/`：原版门禁任务与消息流。
- `Drivers/BSP/password/`：密码缓存、比较和保存。
- `Drivers/BSP/keyboard/`、`Drivers/BSP/w25q128/`：输入与非易失存储。
