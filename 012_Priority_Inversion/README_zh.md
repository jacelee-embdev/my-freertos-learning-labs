# STM32F103C8T6 FreeRTOS 优先级翻转实验

## 项目简介

本实验使用低、中、高三个优先级任务和一个普通二值信号量复现优先级翻转。低优先级任务先获取信号量并执行耗时操作；高优先级任务随后请求同一信号量而进入阻塞；此时中优先级任务抢占低优先级任务，导致低优先级任务无法及时释放资源，高优先级任务也被间接延迟。串口日志按 Low、Middle、High 标记完整显示这一调度顺序。

## 主要功能

- 创建优先级为 1、2、3 的三个测试任务。
- 使用普通二值信号量保护模拟共享资源。
- 通过忙等待构造低任务持锁和中任务抢占场景。
- 展示二值信号量不提供优先级继承的影响。

## 硬件连接

本实验主要通过串口观察，无需按键操作。USART1 使用 PA9（TX）和 PA10（RX），波特率为 115200。所有设备需要共地。

## 使用方法

打开 `Projects/MDK-ARM/STM32F103.uvprojx`，编译下载并连接串口终端。复位后观察三个任务的日志，重点比较高优先级任务开始等待到最终获得信号量之间的延迟。

## 主要文件

- `Drivers/BSP/freertos_test/`：优先级翻转场景与三个任务。
- `Drivers/SYSTEM/delay/`：模拟计算负载。
- `Drivers/SYSTEM/uart1/`：调度过程日志输出。
