# STM32F103C8T6 人员通行流量控制系统（原版）

## 项目简介

本综合实验使用红外传感器统计人员通行次数，并通过闸机、LCD1602、LED 和蜂鸣器实现限流控制。系统默认允许通行，计数型信号量提供 5 个通行名额。每次 PB4 红外中断触发后消耗一个名额，并在 LCD 上显示累计人数；第五人通过后系统进入等待状态，关闭继电器闸机、快速闪烁警示灯并启动蜂鸣器。3 秒单次定时器到期后，名额和通行状态自动复位。

## 主要功能

- 使用计数型信号量表示 5 个通行名额。
- 通过状态队列协调检测任务和设备控制任务。
- 使用显示队列与互斥量集中更新 LCD1602。
- 定时器回调通过任务通知触发系统复位。

## 硬件连接

红外传感器接 PB4，蜂鸣器接 PB5，闸机继电器接 PB6，LED1/LED2 接 PB8/PB9。LCD1602 数据线 D0–D7 接 PA0–PA7，RS、RW、EN 分别接 PB1、PB2、PB10。

## 使用方法

打开 `Projects/MDK-ARM/STM32F103.uvprojx`，编译下载。依次触发红外传感器，LCD 从 `PASS...00/05` 累计到第五次；随后系统显示等待、关闭闸机并报警，约 3 秒后恢复。

## 主要文件

- `Drivers/BSP/freertos_test/`：原版业务任务和 RTOS 资源。
- `Drivers/BSP/exti/`：红外检测中断。
- `Drivers/BSP/lcd1602/`、`Drivers/BSP/relay_gate/`：显示和闸机驱动。
