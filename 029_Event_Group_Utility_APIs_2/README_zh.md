# STM32F103C8T6 FreeRTOS 事件组同步屏障实验

## 项目简介

本实验使用 `xEventGroupSync()` 构建多任务同步屏障。逻辑上由模块 1、模块 2 和主任务三类参与者组成，分别对应 bit0、bit1 和 bit2。主任务进入同步点后等待；按下 KEY1 表示模块 1 就绪，按下 KEY2 表示模块 2 就绪。只有三个事件位全部到达后，等待屏障的任务才会一起解除阻塞，并自动开始下一轮同步。

## 主要功能

- 使用事件组同时设置自身就绪位并等待完整掩码。
- 通过 KEY1、KEY2 模拟两个模块完成初始化。
- 主任务以独立事件位参与同一同步屏障。
- 所有参与条件满足后统一释放等待任务。

## 硬件连接

KEY1、KEY2 分别连接 PA0、PA1，采用内部上拉并在按下时接地。USART1 使用 PA9/PA10，波特率为 115200，用于显示模块和系统同步结果。

## 使用方法

打开 `Projects/MDK-ARM/STM32F103.uvprojx`，编译下载并连接串口。以任意顺序按下 KEY1 和 KEY2；当主任务及两个模块的位全部就绪后，终端会显示模块初始化和全部初始化完成信息。

## 主要文件

- `Drivers/BSP/freertos_test/`：同步屏障及三个逻辑角色。
- `Drivers/BSP/key/`：模块就绪事件输入。
- `Users/FreeRTOSConfig.h`：事件组功能配置。
